Unit Converter

A Python project for converting measurements

About the Project

The Unit Converter is a Python project that converts measurements between different units of distance and temperature. Last updated on October 27th 2026.

Chosen Theme

Unit conversion: distance and temperature.

Team Members

Implemented Features

  • Distance conversions between supported units
  • Temperature conversions between supported units
  • Automated tests using pytest
  • Continuous integration using GitHub Actions

How to Run the Project

Install Python, then open a terminal in the project folder.

pip install -r requirements.txt
python -m pytest -v

These commands install the dependencies and run the test suite.
